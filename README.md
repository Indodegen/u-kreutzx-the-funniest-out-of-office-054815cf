This entry is a tiny program that delivers a single funny out-of-office reply: it reads the one-liner from `entry.txt`, checks that it is exactly one line of 1–140 characters with no stray space at either end, and writes that very same text out for make.fun to judge.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts
```

The validated line lands in `$MAKEFUN_OUTPUT_DIR/entry.txt`.
